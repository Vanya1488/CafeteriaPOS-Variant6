# Анализ метрик качества кода CafeteriaPOS

**МДК 03.02 — вариант №6**

Проект: CafeteriaPOS  
Среда разработки: Visual Studio 2026  
Язык программирования: C#  
Платформа: .NET 8  
Дата исследования: 14.11.2026

## 1. Цель исследования

Оценить качество программного кода CafeteriaPOS, выявить участки с повышенной сложностью, выполнить рефакторинг и сравнить показатели до и после внесённых изменений.

## 2. Используемые показатели

- Maintainability Index — индекс удобства поддержки кода
- Cyclomatic Complexity — цикломатическая сложность
- Class Coupling — взаимозависимость классов
- Lines of Source Code — количество строк исходного кода
- Lines of Executable Code — количество строк исполняемого кода

Измерения выполнены встроенным инструментом «Метрики кода» Visual Studio.

|---|---:|---:|

## 4. Выполненный рефакторинг

До рефакторинга обработка HTTP-запросов, создание заказов, валидация данных и расчёт стоимости находились непосредственно в Program.cs.

После рефакторинга выделен класс OrderService, отвечающий за бизнес-логику работы с заказами.

Program.cs отвечает преимущественно за конфигурацию и маршрутизацию API.

При этом сохранена совместимость маршрутов API V1 и API V2.

## 5. Анализ результатов

Индекс поддерживаемости класса Program увеличился с 29 до 42.

Цикломатическая сложность Program уменьшилась с 16 до 2.

Количество строк исходного кода проекта уменьшилось с 218 до 128.

Общая цикломатическая сложность проекта изменилась с 21 до 20.

При этом взаимозависимость классов проекта увеличилась с 30 до 33 вследствие выделения отдельного сервиса.

Таким образом, рефакторинг позволил упростить структуру Program.cs и отделить бизнес-логику от конфигурации приложения. Однако не все показатели проекта улучшились.
