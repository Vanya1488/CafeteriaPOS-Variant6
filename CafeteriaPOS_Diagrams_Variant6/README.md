# Диаграммы CafeteriaPOS — МДК 03.02, вариант №6

Схемы построены по текущей реализации `Program.cs` и `Services/OrderService.cs`.

| Файл | Назначение |
|---|---|
| `C4_CONTAINER` | C4, уровень контейнеров: одно .NET-приложение, встроенный Swagger UI и данные в памяти |
| `C4_COMPONENT` | C4, уровень компонентов: маршруты, OrderService и списки в памяти |
| `UML_COMPONENT` | UML-подобная диаграмма компонентов с обозначениями программных компонентов |
| `ORDER_FLOWCHART` | Блок-схема обработки заказа с условиями и циклом по позициям |

Для каждой схемы есть **PNG** (вставка в Word), **SVG** (масштабируемая графика) и **DOT** (редактируемый исходник Graphviz).

**Точность нотаций.** C4-схемы являются архитектурными диаграммами с подписанными типами. UML-схема визуально показывает компоненты и контракты; `IOrderOperations` является только концептуальной меткой диаграммы, а не объявленным в коде C# интерфейсом. Блок-схема использует условные формы для процессов/решений/ввода-вывода и перед сдачей на строгую нормоконтрольную проверку может потребовать подгонки размещения стрелок и надписей по локальным методическим требованиям.

В настоящем проекте не используется PostgreSQL: меню и заказы временно хранятся в памяти процесса.
