# CafeteriaPOS — вариант 6

## 1. Описание проекта

CafeteriaPOS — учебная информационная система для автоматизации работы столовой. Проект представляет собой REST API, предназначенный для управления меню и оформления заказов.

## 2. Используемые технологии

- C#
- .NET 8
- ASP.NET Core Minimal API
- Swagger / OpenAPI
- xUnit для автоматизированного тестирования

## 3. Основные возможности

- Получение списка блюд
- Получение списка заказов
- Создание новых заказов
- Проверка корректности количества блюд
- Проверка доступности позиций меню
- Получение информации об отдельном заказе
- Поддержка двух версий API (v1 и v2)
- Проверка состояния приложения через Health Check

## 5. API

| Метод | Маршрут | Назначение |
|---|---|---|
| GET | /api/v1/menu | Получение меню |
| GET | /api/v1/orders | Получение заказов |
| POST | /api/v1/orders | Создание заказа |
| GET | /api/v2/orders | Получение заказов с дополнительными данными |
| GET | /api/v2/orders/{id} | Получение заказа по ID |
| GET | /health | Проверка состояния приложения |

## 7. Запуск проекта

Для запуска необходимо установить .NET 8 SDK.

В терминале Visual Studio выполнить:

```powershell
dotnet restore
dotnet build
dotnet run
```

После запуска Swagger UI доступен по адресу, указанному в консоли приложения.

## 8. Тестирование

Для проверки работоспособности API используются запросы Swagger UI и автоматизированные тесты.

Проверяются:
- Получение меню
- Создание заказа
- Получение списка заказов
- Получение заказа по идентификатору
- Обработка отсутствующего заказа
- Проверка состояния приложения

## 9. Особенности реализации

В текущей учебной версии данные меню и заказов хранятся в оперативной памяти приложения. При перезапуске приложения созданные заказы сбрасываются.
